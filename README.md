# 2nd Year — Week 3 C Programming & DSA

This repository contains my 2nd Year Week 3 C Programming and DSA assignment.

## Topics Covered

### Merge Sort
- Merge Sort using recursion
- Sorting student marks
- Sorting product prices
- Finding lowest and highest salaries
- Calculating salary difference

### Quick Sort
- Quick Sort using recursion
- Sorting time records
- Sorting book IDs
- Sorting salaries in descending order
- Finding the top 3 salaries
- Calculating the average of the top 3 salaries

## Programs

The assignment contains 6 programs:

1. Merge Sort — Sort student marks
2. Merge Sort — Sort product prices
3. Merge Sort — Sort salaries and find the lowest salary, highest salary, and difference
4. Quick Sort — Sort time records
5. Quick Sort — Sort book IDs
6. Quick Sort — Sort salaries in descending order and find the top 3 salaries and their average
